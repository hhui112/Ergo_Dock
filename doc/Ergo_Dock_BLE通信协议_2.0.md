# Ergo_Dock 语音盒床控设备 BLE 通信协议（Ergo_Dock 2.0）

> 文档版本：基于 `Ergo_Dock语音盒床控设备BLE通信协议_20260418` 整理  
> 对照固件：`AIP_v1_1/ble/ble_fota_server`（`x_ble_com.c` 等）  
> 说明：本文件仅描述**业务 BLE 协议**（端口 `0x01` / `0x06` / `0x09`）。固件升级走独立 FOTA 服务（UUID `0x2600`），见凌思微 OTA 文档，不在本文范围。

---

## 一、协议分层框架

本协议分为**链路层**与**应用层**：

| 层级 | 职责 |
|------|------|
| 链路层 | 定义整帧基础格式：帧长 + 端口 + 数据域 |
| 应用层 | 在数据域内承载键值控制、离线语音、打鼾干预、测试信息等业务 |

---

## 二、链路层数据包

### 2.1 帧格式（总长度 2~162 B）

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧长 | 1B | **仅**表示「数据域」字节数，不含本字段与端口 |
| 端口 | 1B | 见下表 |
| 数据域 | 0~160B | 应用层载荷 |

**整帧总长度** = 1（帧长）+ 1（端口）+ 数据域长度。

### 2.2 端口定义

| 端口 | 含义 |
|------|------|
| `0x01` | APP 键值帧 / 主控盒（蓝牙盒）响应帧 |
| `0x06` | 数据段（离线语音 / 打鼾干预 / 测试信息 / 打鼾调试模式） |
| `0x09` | 服务帧 |

### 2.3 字节序约定

- 多字节数值（键值、时间、计数值等）默认 **小端（低字节在前）**，除非字段另行说明。
- 下文示例均为十六进制。

---

## 三、应用层协议

### 3.1 键值控制帧（遥控器 / APP → 主控器）

端口固定 `0x01`。

#### 3.1.1 普通键值帧（数据域 5B，整帧 7B）

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧长 | 1B | 固定 `0x05` |
| 端口 | 1B | 固定 `0x01` |
| 键值 | 4B | 核心控制指令（LE32） |
| 扩展右侧电机键值 | 1B | 双人床右侧；单床填 `0x00` |

**示例：**

```text
05 01 01 00 00 00 00
```

含义：`KEY_M1_OUT`（头部伸出）。

#### 3.1.2 缓启动键值帧（数据域 7B，整帧 9B）

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧长 | 1B | 固定 `0x07` |
| 端口 | 1B | 固定 `0x01` |
| 键值 | 4B | 核心控制指令（LE32） |
| 扩展右侧电机键值 | 1B | 单床填 `0x00` |
| 速度 PWM | 1B | `0x00`~`0xFF`，越大越快 |
| 时间 Time | 1B | 单位：秒 |

**示例：**

```text
07 01 01 00 00 00 00 50 10
```

含义：`M1_OUT`，PWM=`0x50`，时长=`0x10` 秒。

### 3.2 APP 键值响应帧（主控器 → APP）

端口固定 `0x01`。数据域由多段拼接：`BA`（基础头）+ `B9`（键值）+ `B8`（蓝牙盒信息）+ `B7`（主控原始）+ 原始字节流。

整帧示意：

```text
[帧长] [01] [BA ...] [B9 ...] [B8 ...] [B7] [主控 UART 原始帧...]
```

其中固定段 `BA+B9+B8` 共 32 字节（数据域偏移 0~31），其后为 `B7` + 主控原始数据。

#### 3.2.1 基础头段 `0xBA`（数据域偏移 0~9，共 10B）

| 偏移（数据域） | 字段 | 说明 |
|----------------|------|------|
| 0 | 段类型 | 固定 `0xBA` |
| 1 | 床底灯状态 | `0`=关，`1`=开 |
| 2 | 头部按摩强度 | 0 / 1 / 3 / 6 |
| 3 | 脚部按摩强度 | 0 / 1 / 3 / 6 |
| 4~7 | 按摩剩余时间 | LE32，单位与实现一致（固件取自主控 massageTimer） |
| 8 | 支持缓启动 | `0`=不支持，`1`=支持 |
| 9 | 预留 | `0` |

**缓启动能力判定（固件）：** 最近一次主控 MFP 同步帧首字节 `length` 属于下列之一时置 `1`：

| length | 说明 |
|--------|------|
| `0x30` | 原支持缓启动主控 |
| `0x34` | 原支持缓启动主控 |
| `0x2A` | 新增适配 |
| `0x40` | 新增适配 |
| `0x41` | 新增适配 |

#### 3.2.2 键值段 `0xB9`（数据域偏移 10~17，共 8B）

| 偏移 | 字段 | 说明 |
|------|------|------|
| 10 | 段类型 | 固定 `0xB9` |
| 11 | 子类型 | 预留，默认 `0` |
| 12 | 键值来源 | 预留，默认 `0` |
| 13 | 扩展值 | 预留，默认 `0` |
| 14~17 | 核心键值 | LE32，主控当前键值 |

#### 3.2.3 蓝牙盒信息段 `0xB8`（数据域偏移 18~31，共 14B）

| 偏移 | 字段 | 说明 |
|------|------|------|
| 18 | 段类型 | 固定 `0xB8` |
| 19~21 | 软件版本 | 主 / 次 / 修订（当前固件示例：`02 01 00` → V2.1.0） |
| 22~23 | 硬件版本 | 主 / 次（当前固件示例：`02 02` → V2.2） |
| 24~26 | 上电时间 | 时 / 分 / 秒（保留，可为 0） |
| 27~28 | 故障诊断码 | 组 + 代码；`00 00` 正常 |
| 29 | 离线语音状态 | `0`=关；`1`=Hello Ergo；`2`=Hello Bed |
| 30 | 打鼾干预强度 | `0`=关；`1`~`3`=强度 |
| 31 | 无线充状态 | 见实现：`0`/`1`/`0xFF` 等（以固件 `charge_state` 为准） |

#### 3.2.4 主控盒原始数据段 `0xB7`

| 字段 | 说明 |
|------|------|
| 段类型 | 固定 `0xB7` |
| 其后 | 主控 UART 原始同步帧整包（首字节即为协议 `length`，不再单独带 raw 长度字节） |

主控同步帧字段含义（摘要，细节以主控协议为准）：

| 内容 | 说明 |
|------|------|
| length / type | 如 `0x2C` / `0x07` 等，随主控型号变化 |
| keys | 键值 LE32 |
| UBB 等位域 | 床底灯、电机自动运行等标志 |
| pulseCounter / current | 驱动器纹波、电流等 |
| RGB / brightness | 灯效相关 |
| checkSum | 校验和 |

### 3.6 打鼾调试模式（端口 `0x06`，段类型 `0x13`）

用于产测/联调时切换打鼾干预参数；**仅存 RAM，不写 Flash**。上电 / 复位后恒为量产模式（`mode=0`）。

| 模式 | 检测窗 | 强度阈值（1 / 2 / 3） | 干预周期（到期不放平，可再抬升） |
|------|--------|------------------------|----------|
| `0` 量产 | 5 分钟 | 20 / 14 / 7 | 8 小时 |
| `1` 测试 | 60 秒 | 7 / 5 / 3 | 1 分钟 |

PWM / TMR / 强度档位仍由 3.4（`0x11`）或 Flash 配置，本段不改业务参数。

切换 `mode` 时固件会：清当前检测窗、停止抬升段、清周期计时，并按新窗长刷新 `trigTimer`。

#### 3.6.1 查询（APP → 主控器）

```text
02 06 13 B6
```

#### 3.6.2 设置（APP → 主控器）

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧长 | 1B | `0x03` |
| 端口 | 1B | `0x06` |
| 段类型 | 1B | `0x13` |
| 参数 | 1B | `0xB7` |
| mode | 1B | `0x00`=量产；`0x01`=测试；其它非法值忽略并回应当前 mode |

```text
03 06 13 B7 01
```

#### 3.6.3 应答（主控器 → APP）

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧长 | 1B | `0x03` |

## 四、与固件实现的对照要点

| 项目 | 说明 |
|------|------|
| 业务收发 | `x_ble_com.c`：`ble_link_send` / 端口 `0x06` 段分发 |
| 缓启动能力 | `mfp_mainbox_supports_soft_start()`（`x_uart.c`） |
| 打鼾包计数 | `SNORE_OUT`（PA06）上升沿 EXTI → `snoreNub++` |
| 打鼾干预抬升 | 支持缓启动：`0x07`；否则普通键 `0x05`，每段约 2s |
| 打鼾调试模式 | `snore_run_mode_set/get`（`x_snoreintervention.c`），段 `0x13`，仅 RAM |
| FOTA | 独立服务 UUID `0x2600`，与本文业务协议无关 |

## 五、补充说明

1. 所有帧数据均为十六进制表示。
2. 未特别声明时，多字节字段按**小端**解析。
3. 主控原始段（`B7`）长度随主控型号变化，APP 应以 `B7` 后首字节 `length` 解析整包。
4. 原协议文本中部分笔误（如长度写 `0x08`、示例缺字段）已按当前固件行为在本文修正。
5. 若协议与固件不一致，以当前仓库 `x_ble_com.c` / `x_snoreintervention.c` / `offline_voice.c` 为准，并回写本文。
